My project is Old Car Price Prediction.
It is a machine learning based web application developed using Python and Streamlit.
The main objective of this project is to predict the resale price of a used car
based on factors such as car brand, manufacturing year, kilometers driven, fuel type,
transmission and owner type. We train a machine learning model using historical car data.
Categorical features are converted into numerical form using encoding.
The trained model is then integrated with a Streamlit web interface.
The user enters the car details and the model predicts the estimated resale price.
